平板全屏播放器 · 三个布局方向

点侧栏面板左上角的侧栏按钮进入全屏后的样子。设备按 0.5 倍 dp 绘制（横屏 1280×800dp、竖屏 800×1280dp），卡片沿用双卡片风格：避开状态栏与手势条、四周 8dp、圆角 16dp，背景为封面取色。歌词为示意文字。

A

左封面、右信息

横屏：左半边按高度撑满的大封面，右半边依次是歌名歌手、单行歌词、进度条、播放控件、快捷操作，整体垂直居中。竖屏：退化为上下排列，封面按宽度放大。

优点　横屏空间利用最好，封面最大，信息层级和侧栏一致，用户不用重新熟悉。
缺点　横竖屏是两套排版，竖屏和侧栏的差别主要只是变大；看歌词仍要点进歌词页。

B

左播放、右歌词

横屏：左侧一列是封面加控件（和侧栏内容一致），右侧大面积实时滚动歌词，当前句高亮、下方带翻译。竖屏：上方一行紧凑播放区（小封面 + 歌名 + 控件），下方整块是歌词。

优点　全屏多出来的空间用来看歌词，用途明确；横竖屏都能边看歌词边操作，不用再进单独的歌词页。
缺点　纯音乐、无歌词的歌右侧会空，要另做空态；歌词列表要做平板尺寸与点击跳转等适配，工作量最大。

C

居中单列放大

沿用侧栏的竖排结构，内容列按可用高度整体放大并居中，两侧只铺封面取色背景。横竖屏同一套排版，只是放大比例不同。

优点　改动最小、最稳；和当前的临时全屏效果一致，只是把内容列放大，开合动画也最顺。
缺点　横屏两侧留空多，空间利用差；全屏和侧栏的差异不明显，进入全屏的收益较小。
